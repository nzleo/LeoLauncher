LeoLauncher ⌥ Space 呼出的空间分区启动器

一个应用只进一个分类，按 Bundle ID 记住。分类、隐藏与排序随 iCloud 走。点空白或 Esc 关掉。

macOS 14+ · 未做 Apple 公证 · 最新 v1.0.0

它解决什么问题

系统 Launchpad 越来越难用：分类弱、不好找、换机器布局不跟着走。所以自己做了一个：⌥ Space 呼出即开，一个应用只进一个分类，布局跟着 iCloud 走。

一个分类

按 Bundle ID 归类，不是文件路径。同一个应用不会同时出现在两个分区。

布局跟着走

分类、隐藏、排序和使用记录经 iCloud 同步。换机器不用重排。

三种看法

功能分区、图标主色色谱、安装时间轴。同一批应用，三种扫法。

呼出即搜

⌥ Space 打开后直接打字，支持拼音。点空白或 Esc 关闭。

核心能力

面向「呼出、找到、打开」的完整闭环，而不是再造一个程序坞。

分类砌块

按功能砌成列。拖到别的分区立刻覆盖分类并同步。认不出的进「待分」，不会偷偷塞进系统。

颜色与时间

按图标主色排成色谱；或按安装时间看近 7 天 / 1 个月 / 3 个月 / 半年。

覆盖层样式

玻璃、毛玻璃、透明、墨色。招呼语用 Mac 用户名；底部分类栏每次一句名言（内置 40 条，本地）。

触控板与 TourBox

默认 ⌥ Space / ⌥⇧ Space 打开，⌃ Space 搜索。也可用 leolauncher://show 给 BTT 或 TourBox 绑定。

⌥ Space 拼音搜索 iCloud 同步 待分 玻璃 / 毛玻璃 / 透明 / 墨色 图标+名称 / 仅图标 Bundle ID 底栏名言

下载与安装

不用编译。下载 DMG，把 App 拖进「应用程序」，按住 Control 打开一次即可。

  1. 下载 DMG 并拖进「应用程序」

    从 Releases 下载 LeoLauncher-*.dmg，把 App 拖到 Applications 文件夹。

  2. 首次打开手动放行

    未做 Apple 公证，会被 Gatekeeper 拦。按住 Control 点击 App → 打开 → 再点打开。或：xattr -dr com.apple.quarantine /Applications/LeoLauncher.app

  3. 按 ⌥ Space 呼出

    弹出后直接打字搜索，支持拼音。点空白或 Esc 关闭。快捷键可在设置里改。

首次打开必看

「无法验证开发者」是正常的

这个 App 没有购买每年 99 美元的开发者证书，也未做公证。系统拦一下不代表文件损坏。

  1. 在「应用程序」里找到 LeoLauncher
  2. 按住 Control 键点击 → 选择「打开」
  3. 弹窗里再点一次「打开」

命令行最快

xattr -dr com.apple.quarantine /Applications/LeoLauncher.app

从源码构建（可选）

一般用户请直接下载 DMG。下面给想自己编译的开发者。

  1. 克隆仓库

    git clone https://github.com/nzleo/LeoLauncher.git

  2. 打包 App 或 DMG

    make dmg 生成 dist/LeoLauncher-*.dmg。只要 App：./Scripts/package-app.sh。装进本机：make install。

下载并开始用

免费开源。拖进「应用程序」，Control 点击打开，然后按 ⌥ Space。
